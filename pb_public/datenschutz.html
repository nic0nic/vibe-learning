Datenschutz

Kurz gesagt: Auf dem Server stehen keine Namen. Wer einen Zugang der Lehrkraft nutzt, wird nur über einen Code oder einen Benutzernamen ohne Klarnamen erkannt. Gespeichert wird, welche Aufgaben gelöst wurden. Es gibt keine Cookies, keine Werbung, kein Tracking und keine Dienste anderer Anbieter. Ohne Anmeldung bleibt alles im eigenen Browser.

2. Nutzung ohne Anmeldung

Alle Übungen lassen sich ohne Anmeldung nutzen („Seite ohne Anmeldung nutzen“). Der Übungsfortschritt wird dann nur im eigenen Browser gespeichert (siehe Nr. 5) und nicht an den Server übertragen.

3. Aufruf der Seiten (Server und Protokolle)

Beim Aufruf einer Seite verarbeitet der Server technisch notwendig die IP-Adresse des Geräts, den Zeitpunkt und die angeforderte Datei, um die Seite auszuliefern. Der Server führt ein Protokoll der Anfragen ohne IP-Adressen; es wird nach 7 Tagen automatisch gelöscht. Zweck ist der sichere und fehlerfreie Betrieb. Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse am sicheren Betrieb).

Die Verbindung ist per HTTPS verschlüsselt.

4. Nutzung mit Zugang der Lehrkraft

Die Lehrkraft kann Zugänge ausgeben: einen Zugangscode (z. B. 8B-K7Q2-M4XZ) oder einen Benutzernamen mit Passwort. Benutzernamen enthalten keine echten Namen. Mit einem Zugang wird auf dem Server gespeichert:

  • der Code bzw. der Benutzername, bei Benutzernamen das Passwort nur verschlüsselt (bcrypt),
  • die Klassenbezeichnung (z. B. „8b“),
  • der Übungsstand der einzelnen Übungen, damit man an anderen Geräten weiterarbeiten kann,
  • welche Aufgaben und Erklärschritte gelöst wurden, jeweils mit Zeitpunkt,
  • beim Tipptrainer: Ergebnisse der Tipp-Tests (z. B. Anschläge bzw. Wörter pro Minute, Genauigkeit, Dauer, Zeitpunkt) und der Stand bei Aufgaben der Lehrkraft.

Nicht gespeichert werden Namen, falsche Antworten oder wie lange jemand auf einer Seite war.

Zweck: Die Lehrkraft sieht für ihre Klassen, wer im gewählten Zeitraum welche Aufgaben gelöst hat (z. B. zur Kontrolle von Hausaufgaben). Die Zuordnung von Codes bzw. Benutzernamen zu Schülerinnen und Schülern kennt nur die Lehrkraft. Eine Namensliste dazu speichert die Verwaltung nur im Browser der Lehrkraft, nie auf dem Server. Lehrkräfte sehen nur ihre eigenen Klassen.

Rechtsgrundlage: Einwilligung (Art. 6 Abs. 1 lit. a DSGVO). Bei Schülerinnen und Schülern unter 16 Jahren willigen die Erziehungsberechtigten ein. Die Einwilligung ist freiwillig und kann jederzeit mit Wirkung für die Zukunft widerrufen werden; die Übungen bleiben ohne Anmeldung nutzbar.

Speicherdauer: Die Daten werden spätestens am Ende des Schuljahres gelöscht, bei einem Widerruf oder auf Wunsch früher. Mit dem Löschen eines Zugangs bzw. einer Klasse werden auch Fortschritt, Protokoll und Tipp-Ergebnisse gelöscht.

5. Speicherung im Browser

Die Seite setzt keine Cookies. Damit die Übungen funktionieren, speichert sie Daten im Browser des eigenen Geräts (localStorage, sessionStorage, IndexedDB):

  • den Übungsfortschritt und Einstellungen der Übungen (z. B. hell/dunkel, zuletzt gewähltes Fach),
  • nach einer Anmeldung den Code bzw. Benutzernamen, damit man angemeldet bleibt (bis zum Abmelden; Lehrkräfte bis zum Schließen des Browsers),
  • beim Tipptrainer die eigenen Ergebnisse und Einstellungen.

Diese Speicherung ist für die gewünschte Funktion unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG); eine Einwilligung ist dafür nicht nötig. Die Daten lassen sich jederzeit über die Browser-Einstellungen („Websitedaten löschen“) entfernen. An gemeinsam genutzten Geräten (z. B. Schul-PCs) bitte nach dem Üben abmelden – oben rechts auf den eigenen Code bzw. Namen klicken.

6. Keine Dienste anderer Anbieter

Alle Dateien (auch Schriften und Programmbibliotheken) kommen vom eigenen Server. Es werden keine Analyse-, Werbe- oder Social-Media-Dienste eingebunden und keine Daten an Dritte weitergegeben.
